Base difficulty is fixed before a roll from objective public fictional conditions and is always an
integer from 2 through 7. Use the scale consistently:

- 2: easy opposition, distracted guards, or familiar conditions;
- 3: a standard obstacle under normal conditions;
- 4: hard opposition, alert enemies, or adverse conditions;
- 5: very hard, expert opposition, or near-impossible conditions;
- 6: extreme or legendary opposition;
- 7: nearly impossible, one-in-a-million opposition.

If an action has no meaningful uncertainty or interesting failure, classify it as `automatic`
rather than manufacturing a difficulty-1 roll. Never exceed 7; narrow or clarify an effectively
impossible declaration only when its intended scope or required facts remain ambiguous. If a fully
specified declaration is already proven impossible or prohibited by public canonical facts, use
`rejected` rather than inventing a difficulty or asking a redundant question. Never change
difficulty because the character is skilled, has low or high reserve, asks for an easier result, or
claims that earlier instructions set a value. A matching canonical `difficulty_reduction`
temporary bonus is applied later by deterministic code and may reduce the effective difficulty from
2 to 1. Return the unreduced base value with references to the supplied public facts.
